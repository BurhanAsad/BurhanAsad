#  House Price EDA – Exploratory Data Analysis

##  Project Overview

This project focuses on Exploratory Data Analysis (EDA) of house prices using Python. The main aim is to understand how different factors like house quality, living area, neighbourhood and construction year affect house selling prices.

The analysis is performed using the Ames Housing Dataset from Kaggle.

## 🎯 Project Objectives

- Understand and analyse the house price dataset.
- Identify missing values and duplicate records.
- Calculate important statistical measures.
- Study relationships between different variables.
- Detect outliers using IQR and Z-score.
- Create graphs and visualisations.
- Build a final EDA dashboard.

## 📂 Dataset Information

- **Dataset:** Ames Housing Dataset
- **Source:** Kaggle
- **Competition:** House Prices – Advanced Regression Techniques
- **File:** train.csv
- **Rows:** 1,460
- **Columns:** 81
